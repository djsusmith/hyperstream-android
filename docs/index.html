Engineered for Extreme Mobile Speed

Unmatched mobile freedom, zero GC latency, and state-of-the-art native Rust acceleration.

⚡

128-Thread Segmented Engine

Dynamic work-stealing segment halving down to 12 KB chunks. Slow or stalled socket connections are shed in real-time to keep your bandwidth fully saturated.

🧲

Full BitTorrent Swarm Client

Powered by librqbit with native DHT, PEX, LSD, and UPnP. Features sequential video streaming mode so you can watch movies while they download.

🎬

Universal Smart Media Sniffer

Catches YouTube 4K/8K streams, watermark-free TikTok videos, Instagram Reels, and Facebook HD. Includes automatic 320 kbps MP3 audio conversion.

📂

Instant 1-Tap Open & Safe Delete

Integrated AndroidX FileProvider launches downloaded files and APK installers immediately. Includes permanent deletion confirmation with storage purge.

🔋

Partial WakeLock & High-Perf Wi-Fi

Foreground download service holds Android CPU Partial WakeLock and Wi-Fi High-Performance lock so multi-gigabyte transfers finish even with screen locked.

🛡️

Elevated Shizuku Power Tools

Optional uid=2000 ADB capabilities via Shizuku: 1-tap Android Doze battery whitelisting and silent background app updates without root.
